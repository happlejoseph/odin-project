# The Odin Project Website Clone

A responsive front-end clone of **The Odin Project** website built using **HTML and Tailwind CSS**.  
This project is created for practice purposes to improve UI design and Tailwind CSS skills.

## 🚀 Features

-  Fully responsive layout
-  Built with Tailwind CSS utility classes
-  Navigation bar similar to original site
-  Homepage UI replica
-  Sections like curriculum, learning path, and info layout
-  Clean and modern design

## 🛠️ Built With

- HTML5
- Tailwind CSS
